# Такси Кликер

Мобильная игра-кликер про такси. Движок Godot 4.7, язык GDScript.

## Как открыть

1. Скачайте Godot 4.7 с сайта [godotengine.org](https://godotengine.org/download). Нужна обычная версия, не .NET.
2. Запустите Godot и нажмите **Импорт**.
3. Укажите файл `project.godot` в этой папке и подтвердите импорт.
4. Нажмите **F5** (или кнопку запуска в правом верхнем углу).

Окно на компьютере откроется узким, как экран телефона. Игра сама сохраняется.

Вкладка **Настройки** (кнопка справа сверху) умеет стереть прогресс. Это только для проверки.
