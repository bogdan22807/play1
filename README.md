# Такси Кликер

Мобильная игра-кликер про такси. Движок Godot 4.7, язык GDScript.

## Как открыть

1. Скачайте Godot 4.7 с сайта [godotengine.org](https://godotengine.org/download). Нужна обычная версия, не .NET.
2. Запустите Godot и нажмите **Импорт**.
3. Укажите файл `project.godot` в этой папке и подтвердите импорт.
4. Нажмите **F5** (или кнопку запуска в правом верхнем углу).

Окно на компьютере откроется узким, как экран телефона. Игра сама сохраняется.

Вкладка **Настройки** (кнопка справа сверху) умеет стереть прогресс. Это только для проверки.

## Играть на телефоне

**Ссылка (iPhone и Android):** https://bogdan22807.github.io/play1/ — веб-версия из ветки `gh-pages`.
Откройте в Safari (iPhone) или Chrome (Android) и выберите «Поделиться → На экран „Домой"» —
игра появится на экране как приложение, с иконкой, без адресной строки.
Нужно один раз включить GitHub Pages: репозиторий → **Settings → Pages → Source: Deploy from a branch →
Branch: `gh-pages`, папка `/ (root)` → Save**. Через минуту ссылка заработает.

**Android-приложение (APK):** установите файл `TaxiClicker.apk` — разрешите установку из этого источника,
когда телефон спросит. Пресет `Android` в проекте.

**iPhone как приложение (App Store / TestFlight)** собирается только на Mac с Xcode: в Godot выберите
пресет `iOS`, впишите свой Team ID из Apple Developer, экспортируйте и откройте проект в Xcode.

**Обновить веб-версию:** экспорт пресета `Web` в `build/web/`, затем содержимое папки — в ветку `gh-pages`.

## Сборка под Android

Пресет экспорта уже лежит в проекте (`export_presets.cfg`, пакет `com.bogdan22807.taxiclicker`).
Нужно один раз поставить инструменты:

1. **JDK 17** — например, [Adoptium Temurin 17](https://adoptium.net/temurin/releases/?version=17).
2. **Android SDK** — проще всего через [Android Studio](https://developer.android.com/studio):
   в SDK Manager отметьте *Android SDK Platform-Tools*, *Build-Tools* и *Command-line Tools*.
3. В Godot: **Редактор → Настройки редактора → Экспорт → Android** — укажите путь к Android SDK
   и к JDK.
4. В Godot: **Редактор → Управление шаблонами экспорта → Скачать и установить** (для 4.7).
5. **Проект → Экспорт → Android → Экспортировать проект**, снимите галочку «Экспорт с отладкой»
   для финальной сборки. Готовый файл — `build/taxi-clicker.apk`.

Отладочный ключ Godot создаёт сам. Для публикации в Google Play понадобится свой ключ
(release keystore): его путь и пароль вводятся в том же окне экспорта, в разделе *Keystore*.

Быстрый способ проверить на телефоне: включите на телефоне «Отладку по USB», подключите кабелем —
в правом верхнем углу Godot появится значок Android, игра запустится на телефоне одним нажатием.
